# large-scale-optimization
Optimization models and algorithms for large-scale transportation and logistics problems
## Topics Covered
- Network Flow Optimisation
- Inventory Routing Problems
- Facility Location Problems
- Hub Location Problems
- Mixed Integer Linear Programming (MILP)
- Mixed Integer Non Linear Programming (MINLP)
- Benders Decomposition
- Generalized Benders Decomposition (GBD)
- Kelley Cutting Plane Method
- Convexification Techniques
- Transportation and Logistics Analytics
## Tools
- Python
- Gurobi
- NumPy
- NetworkX
- Jupyter Notebook
